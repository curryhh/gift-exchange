# 交换好运 · 好友礼物交换

一个手机优先、温暖欢快的多人转盘抽签与礼物交换网页。无须安装、无须构建、无须账号；支持 GitHub Pages 根目录和项目子目录部署。

新版采用暖米白、番茄红和橄榄绿，配上原创卡通礼盒插画、邀请函、参与徽章和礼物清单。主题适合朋友聚会、生日、节日、团建等场合。主要插画是 assets/gift-party.svg，所有素材随包提供。

## 怎么玩

1. 房主打开页面，点击「发起交换局」，输入昵称，生成随机的 6 位房间号。
2. 点击「复制邀请」发给朋友。朋友打开链接输入昵称即可加入，也可以在首页点击「加入交换局」输入房间号。
3. 支持 2–20 人，房主确认到齐后点击「人到齐了，揭晓送给谁」。
4. 每个人的手机显示自己的转盘，约 7.5 秒后揭晓结果。结果中的「送给」表示你将礼物送给那位朋友；结束后可以查看全场礼物清单。
5. 房主可保留原班人马再开一轮，也可以结束房间。等待区可加入新成员，开奖后名单固定。

首页的「先试一局，看看怎么玩」可以添加虚拟伙伴，在没有网络时完整体验流程。演示房间只存在于当前标签页，不能让其他手机加入；联机失败会明确提示，不会悄悄切换成演示。

## 抽奖规则

- 每位参与者都抽中一个送礼对象，也恰好被另一个人抽中一次：每人送出一份礼物、收到一份礼物。
- 绝不会抽到自己，同一轮内目标不会重复。
- 使用浏览器的加密随机数和 Fisher–Yates 洗牌，再拒绝所有有自我配对的排列，对合法完整配对进行均匀抽样。
- 先生成整轮配对，再播放转盘，避免逐个抽取导致最后一位只剩自己。
- 房主统一处理加入和开奖请求，避免同时加入互相覆盖。重复点击开始不会重抽本轮。
- 规则按「一轮」计算；再次开一轮后，可能再次抽到往轮的同一个人。
- 不阻止两人互相抽中。只有两个人时，结果必然是互相抽中。

## 部署到 GitHub Pages

将此文件夹内的**全部内容**上传到仓库根目录，尤其不要漏掉 assets 文件夹、core.js、sync.js、mqtt.min.js 和 .nojekyll。不要只上传 index.html，也不要上传外面的整个文件夹后把首页藏到二级目录。

1. 在 GitHub 新建仓库，上传解压后的全部文件并提交。
2. 进入仓库 Settings → Pages。
3. 在 Build and deployment 中，Source 选择 Deploy from a branch。
4. 选择存放文件的分支（通常为 main）和 / (root)，点击 Save。
5. 发布完成后，使用 Pages 页面显示的链接。让朋友也用这个线上链接打开，不能把本机 localhost 地址发给朋友。

网站无需 npm install 或 build。所有脚本、头像均在包内，文件路径使用相对路径，适配 GitHub 项目站点的仓库名子路径。

## 多人同步的实际要求

GitHub Pages 承载静态网页。这个版本通过 config.js 中配置的 MQTT WebSocket 服务传递房间状态，默认地址是 wss://broker.emqx.io:8084/mqtt，不需要填写 API Key。

- 所有参与者都要联网，并能访问同一个 MQTT 地址。不同网络可能限制 WebSocket 或 8084 端口。
- 房主的页面负责统一处理请求。活动中请保持房主页面打开、手机亮屏；关闭、锁屏或长时间切后台可能让房间暂时不可用。
- 正常刷新同一个浏览器标签页会尝试恢复成员身份和房间；清理浏览器数据、更换浏览器或新开标签页会获得新身份。房主离开房间会结束房间。
- 房间有效期为 24 小时。首次连接约需数秒；断线后会尝试自动重连，页面会显示提示。
- 通过加入时的往返消息估算房主时钟差，再按同一开奖时间播放。动画受手机性能和网络延迟影响，不能保证每台手机逐帧一致。

默认服务为公共测试服务，适合朋友聚会。房间号不是密码，昵称和完整配对会经过公共主题，不能作为保密抽签或有价值奖品活动的防作弊系统；懂技术的人能在动画结束前查看配对。公共服务的可用性和消息保留时间无法由本页面保证。正式长期使用建议接入自有、带服务器权限校验的房间服务。

如果已有自己的 MQTT WebSocket 服务，可编辑 config.js 的 mqttBroker 地址。HTTPS 页面必须使用 wss://。此文件会公开，不能在这里写秘密密钥。所有手机需要使用同一个网页配置；仅替换公共地址不会自动获得服务器鉴权能力。

## 本地预览

推荐使用任意静态 HTTP 服务器，例如在本文件夹打开终端运行：

    python -m http.server 8765

然后打开 http://localhost:8765 。不要直接双击 HTML 使用 file://，该方式在部分浏览器中不支持所需功能。可用较新的 Safari、Chrome、Edge，或选择手机浏览器打开；内嵌浏览器存在连接限制时，请使用系统浏览器。

## 文件说明

- index.html：页面结构。
- style.css：响应式布局、邀请函、礼物转盘、结果小票和动画；尊重系统减少动态效果设置。
- core.js：随机配对、房间操作和数据校验。
- sync.js：MQTT 房间通信、房主请求队列、离线演示。
- app.js：页面交互、动画和结果展示。
- config.js / config.example.js：服务地址。
- mqtt.min.js：随包提供的 MQTT.js 浏览器客户端。
- assets/：原创礼盒插画、网站图标和旧版素材及其许可证；新版参与徽章直接显示昵称首字。
- .nojekyll：让 Pages 直接发布静态资源。
- THIRD_PARTY_NOTICES.md：第三方素材和库的许可信息。
